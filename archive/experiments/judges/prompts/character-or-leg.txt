Metaphor: the reference is a dictionary of the characters of the Juju story. A character is a thing a user, operator or charm author deals with by itself and looks up by its own name. A leg is a part a reader would only expect on the character's page. A mechanism is a process or rule. For each of 39 pages and 6 candidates decide character, leg (of which character) or mechanism from the code: how users address it by itself (command, flag, facade, API method, hook tool, config key, status line), what refers to it by name, whether it has its own identity (name or id a user types) and its own lifecycle (created and removed by an operation, not only as a side effect). A thing with no user-facing address that only the controller uses is a leg or mechanism unless an operator would query it in the database shell. JSON list with verdict, leg_of, addressed_by, referenced_by, own_identity, own_lifecycle, confidence.
