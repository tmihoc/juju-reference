Audit a proposed grouping of database tables into reference page units. For each group decide from the code whether each table belongs on ONE reference page about that noun (a page a user would read to learn what the thing is, how it is stored, its lifecycle and operations). Flag tables that do not belong with the reason, file:line evidence and where they belong; for groups merged by a rule say whether the merge is right; say whether the noun is one thing or two sharing a word. A shared prefix or a foreign key is not a reason by itself. JSON list of {group, tables_total, flagged[{table,reason,evidence,belongs_in}], merge_verdict, one_thing_or_two, note}.
